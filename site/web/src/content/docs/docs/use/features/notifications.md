---
title: "Notifications"
description: "In-app, push and email notifications."
---

Looty notifies you of mentions, assignments, announcements and reminders, in the app's inbox.

- **Web and iPhone**: web push notifications (on iPhone, add Looty to the home screen first).
- **Android**: UnifiedPush, with no Google services. Install a UnifiedPush distributor (for example ntfy) and choose it in the app.
- **Desktop**: system notifications.
- **Email**: if your instance has email set up, some notifications are also sent by email.

Your administrator must have email and push configured: see [email and push for hosts](/docs/host/services/).
