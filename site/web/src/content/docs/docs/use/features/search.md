---
title: "Keywords and search"
description: "Find anything in a workspace and add keywords to items."
---

The search bar looks through documents, projects, files, boards, tasks and events of the workspace.

- A **keyword** is a free term you put on an item so it can be found even if the word is not in its content (a course code, "exam"…). Keywords are shared across the workspace and carry neither color nor rights; they are different from the colored labels of a board.
- Type `#keyword` in the search to list only the items that carry it.
