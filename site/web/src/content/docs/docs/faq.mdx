## Do you offer hosting?

No, deliberately. Looty is software you run yourself, so that your team keeps its data and nobody depends on us staying in business. The [hosting guide](/docs/host/) is the way to get an instance. There is a [public demo](https://demo.looty.untypequicode.fr) with fictional data, but nothing is kept there.

## Is my data with you?

No. We never see your instance: the apps connect to the server you or your organisation run. This website only distributes the apps and update information.

## Do I need an OpenID Connect provider?

Looty signs people in through OpenID Connect, which we recommend. If you have none, the [bundled Pocket ID](/docs/host/sign-in/pocket-id/) is set up for you with passkeys, in the same compose file. [Local accounts](/docs/host/sign-in/local-accounts/) exist too, but are not recommended.

## Does it work offline?

Yes, in the Android and desktop apps: your boards, documents and calendar are kept on the device, you can edit without a connection and changes merge when you reconnect. The web version needs a connection.

## What about iPhone?

There is no App Store app. Open your instance in Safari and add it to the home screen: it opens full screen and can send notifications.

## How do I migrate from Trello or Notion?

Looty imports a Notion export (Markdown and CSV zip), an Obsidian folder and a Trello board (JSON), with a report of what could not be imported. Boards export as CSV too. See the [comparison pages](/docs/compare/) for what differs.

## How many resources does it need?

A small VPS with 2 GB of RAM is enough for a team. See the [requirements](/docs/host/requirements/).

## What is the license?

Looty is free software under the GPL-3.0 license. The source code is on [GitHub](https://github.com/untypequicode/looty).
