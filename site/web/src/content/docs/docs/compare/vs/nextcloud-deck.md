**Nextcloud Deck**: a kanban app that runs inside a Nextcloud server.

## Where Looty is stronger

- Stands alone: you do not need to run a whole Nextcloud.
- Collaborative documents with live cursors, diagrams, notebooks and LaTeX built in.
- Native Android and desktop apps designed around offline use.

## Where Nextcloud Deck is stronger

- If you already run Nextcloud, Deck is already there, integrated with your files, contacts and sign-in.
- Nextcloud has a very large app ecosystem and a long track record.
- A single Nextcloud covers file sync, which Looty only partly does.

## Choose Looty if… / Nextcloud Deck if…

Choose Looty for a focused workspace with its own apps. Choose Deck if your team already lives in Nextcloud.
