## Proposez-vous un hébergement ?

Non, volontairement. Looty est un logiciel que vous faites tourner vous-même, pour que votre équipe garde ses données et que personne ne dépende de notre survie. Le [guide d’hébergement](/fr/docs/host/) est le chemin pour avoir une instance. Il existe une [démo publique](https://demo.looty.untypequicode.fr) avec des données fictives, mais rien n’y est conservé.

## Mes données sont-elles chez vous ?

Non. Nous ne voyons jamais votre instance : les apps se connectent au serveur que vous ou votre organisation faites tourner. Ce site ne fait que distribuer les apps et les informations de mise à jour.

## Faut-il un fournisseur OpenID Connect ?

Looty ne connecte les gens que par OpenID Connect. Si vous n’en avez pas, le [Pocket ID inclus](/fr/docs/host/sign-in/pocket-id/) est configuré pour vous, avec des passkeys, dans le même fichier compose.

## Ça marche hors ligne ?

Oui, dans les apps Android et bureau : vos tableaux, documents et agenda restent sur l’appareil, vous pouvez modifier sans connexion et les changements fusionnent à la reconnexion. La version web demande une connexion.

## Et sur iPhone ?

Il n’y a pas d’app sur l’App Store. Ouvrez votre instance dans Safari et ajoutez-la à l’écran d’accueil : elle s’ouvre en plein écran et peut envoyer des notifications.

## Comment migrer depuis Trello ou Notion ?

Il n’y a pas encore d’import en un clic. Vous pouvez exporter votre ancien outil en CSV ou Markdown puis coller ou recréer le contenu ; Looty exporte aussi les tableaux en CSV. Les [pages de comparaison](/fr/docs/compare/) détaillent les différences.

## Combien de ressources faut-il ?

Un petit VPS avec 2 Go de RAM suffit pour une équipe. Voir les [prérequis](/fr/docs/host/requirements/).

## Quelle est la licence ?

Looty est un logiciel libre sous licence GPL-3.0. Le code source est sur [GitHub](https://github.com/untypequicode/looty).
