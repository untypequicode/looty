---
title: "Espaces et rôles"
description: "Espaces, membres, rôles et invitations dans Looty."
---

Un **espace** réunit les membres, tableaux, documents et agenda d’une équipe, d’une classe ou d’un projet. Vous appartenez à autant d’espaces que vous êtes invité, et vous avez aussi un **espace perso** que vous seul voyez.

- Les **rôles** décident de ce que chaque membre peut faire (lire, modifier, administrer, publier des annonces…). Les administrateurs les règlent dans les paramètres de l’espace.
- **Invitations** : les administrateurs invitent par lien ou par e-mail ; des invités peuvent recevoir un accès limité.
- **Onglets** : les pages que vous ouvrez restent dans la barre d’onglets de l’espace, chacune avec son propre chemin, comme dans un navigateur.
