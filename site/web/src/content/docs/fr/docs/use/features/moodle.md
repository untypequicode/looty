---
title: "Moodle"
description: "Parcourir vos cours, notes et fichiers Moodle depuis Looty."
---

Si votre établissement utilise Moodle, reliez votre compte une fois et utilisez-le depuis Looty.

- **Connexion automatique** : ouvrez le site Moodle déjà connecté, sans ressaisir vos identifiants.
- **Tableau de bord Moodle** : des panneaux (échéances, cours, dossier, cours épinglé…) que vous placez et redimensionnez librement sur une grille. Ce n’est pas un tableau de tâches.
- **Cours** : les cours favoris (étoile) et masqués sont les mêmes dans Looty et sur le site Moodle. Créez vos **dossiers de cours** dans Looty pour regrouper des cours ; ils n’existent pas sur Moodle. Les **catégories** Moodle restent celles de l’établissement.
- **Personnalisation** : donnez à un cours un nom court, une couleur et une icône, pour vous seul.
- **Notes** : Looty lit votre carnet de notes Moodle (note du cours, éléments, barème, commentaire de l’enseignant) sans pouvoir le modifier.
- **Hors ligne** : gardez les fichiers d’un cours sur l’appareil.
