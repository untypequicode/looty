---
title: "Éléments personnels"
description: "Documents, tableaux et tâches que vous seul voyez, même dans un espace partagé."
---

Un **élément personnel** est un document, projet, fichier du Drive, tableau ou tâche d’un espace partagé visible de son seul propriétaire, même pas des administrateurs : votre TP sous la page du cours, votre notebook dans le projet du groupe. Ce qui est rangé dedans le reste aussi.

- Seule la personne qui crée un élément peut le rendre personnel, et seul son propriétaire peut le repartager.
- Si vous quittez l’espace, vos éléments personnels partent dans votre espace perso, sous le nom de l’ancien espace.
- À ne pas confondre avec votre **espace perso**, qui est un espace privé à part entière.
