---
title: "Modèles"
description: "Partir d’un modèle de tableau ou de document, et enregistrer les vôtres."
---

Un **modèle** est un tableau ou un document prêt à l’emploi pour démarrer.

- **Nouveau tableau** : choisissez un modèle dans la fenêtre de création. **Nouveau document** : utilisez **Depuis un modèle…** dans le menu Nouveau.
- **Modèles fournis** : Suivi de projet et Rétrospective (tableaux), Compte rendu de réunion, Notes de cours et Compte rendu de TP (documents), dans votre langue.
- **Les vôtres** : les administrateurs d’un espace enregistrent un tableau (réglages du tableau) ou un document (menu de la page) comme modèle. Les membres qui peuvent créer des tableaux ou des documents les voient.

Un modèle de tableau garde les colonnes, les étiquettes et les tâches ouvertes (titres, descriptions, priorités, étiquettes, sous-tâches). Les personnes, les dates et l’avancement ne sont pas repris. Un modèle de document garde le titre, l’icône et le contenu.

Les éléments personnels ne deviennent jamais des modèles. Modifier ou supprimer un modèle ne change pas ce qui en a été créé. Gérez-les dans **Réglages > Modèles**.
