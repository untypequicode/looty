---
title: "Groupes"
description: "Nommer des ensembles de membres pour les mentionner ou les assigner ensemble."
---

Un **groupe** est un ensemble nommé de membres d’un espace. Il ne donne aucun droit : il évite seulement de choisir les personnes une par une.

- Mentionnez un groupe pour prévenir tous ses membres.
- Assignez un groupe à une tâche ou un événement, ou adressez-lui une annonce.
- Une personne peut appartenir à plusieurs groupes.

Un groupe ajouté à une tâche, un événement ou une annonce est **relié** : un membre ajouté au groupe y est assigné (ou voit l’annonce), un membre retiré en est retiré, sauf s’il y était aussi individuellement ou par un autre groupe relié. Les tâches terminées ne bougent plus, et supprimer le groupe laisse les personnes en place.
