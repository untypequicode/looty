---
title: "Mots-clés et recherche"
description: "Retrouver n’importe quoi dans un espace et ajouter des mots-clés aux éléments."
---

La barre de recherche parcourt les documents, projets, fichiers, tableaux, tâches et événements de l’espace.

- Un **mot-clé** est un terme libre posé sur un élément pour le retrouver même si le mot n’apparaît pas dans son contenu (code du cours, « partiel »…). Les mots-clés sont communs à l’espace, sans couleur ni droit ; ils diffèrent des étiquettes colorées d’un tableau.
- Tapez `#mot-clé` dans la recherche pour ne lister que les éléments qui le portent.
